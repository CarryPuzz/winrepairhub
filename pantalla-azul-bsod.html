Pantalla azul de la muerte (BSOD) – Cómo reparar Windows 10 y 11

Guía 📅 Actualizado: 2024 ⏱ Lectura: ~5 min 🖥️ Windows 10 & 11

La pantalla azul de la muerte (Blue Screen of Death, BSOD) es uno de los errores más temidos en Windows. Aparece de repente, congela el ordenador y puede provocar la pérdida de datos no guardados. Esta guía te explica cómo identificar la causa y reparar definitivamente el BSOD en Windows 10 y Windows 11.

¿Qué es una pantalla azul y por qué aparece?

El BSOD es un mecanismo de protección de Windows. Cuando el sistema detecta un error crítico que podría corromper datos, se detiene automáticamente y muestra esta pantalla azul con un código de error.

Causas más frecuentes del BSOD:

  • Controladores corruptos u obsoletos – especialmente los de la tarjeta gráfica
  • RAM defectuosa – errores de memoria o módulos dañados
  • Sobrecalentamiento del procesador o tarjeta gráfica
  • Archivos del sistema Windows corruptos
  • Problemas de disco duro – sectores defectuosos
  • Virus y software malicioso
  • Hardware incompatible tras una actualización

Leer e interpretar el código de error

Cada pantalla azul muestra un código de error que identifica la causa del problema. Anota este código:

DRIVER_IRQL_NOT_LESS_OR_EQUAL SYSTEM_THREAD_EXCEPTION_NOT_HANDLED CRITICAL_PROCESS_DIED PAGE_FAULT_IN_NONPAGED_AREA

Códigos BSOD más comunes:

  • DRIVER_IRQL_NOT_LESS_OR_EQUAL – problema de controlador
  • PAGE_FAULT_IN_NONPAGED_AREA – problema de RAM
  • NTFS_FILE_SYSTEM – error del sistema de archivos
  • CRITICAL_PROCESS_DIED – proceso crítico terminado
  • MEMORY_MANAGEMENT – gestión de memoria defectuosa
💡 Consejo: Busca el código exacto en Google – normalmente encontrarás la causa precisa y la solución para tu configuración.

Método 1: Actualizar los controladores

  1. Pulsa Win + X y abre el Administrador de dispositivos
  2. Busca dispositivos con un signo de exclamación amarillo
  3. Clic derecho → Actualizar controlador
  4. Elige Buscar controladores automáticamente
  5. Reinicia el ordenador tras la actualización
⚠️ Importante: Descarga siempre los controladores de tarjeta gráfica directamente del sitio del fabricante: NVIDIA GeForce Experience o AMD Radeon Software.

Método 2: Verificar archivos del sistema (SFC)

Los archivos del sistema corruptos causan frecuentemente BSOD. La herramienta SFC los repara automáticamente:

  1. Pulsa Win + X y elige Terminal (Administrador)
  2. Escribe el siguiente comando y pulsa Intro:
sfc /scannow

El análisis dura entre 5 y 30 minutos. Windows repara automáticamente los errores encontrados. Reinicia el PC al terminar.

Método 3: Comprobar la memoria RAM

  1. Pulsa Win + R, escribe mdsched.exe y pulsa Intro
  2. Elige Reiniciar ahora y buscar problemas
  3. Windows reinicia y realiza una prueba completa de memoria
  4. Los resultados se muestran al iniciar sesión
💡 Consejo: Si la prueba detecta errores de memoria, deberás reemplazar el módulo RAM defectuoso – los errores de RAM no se pueden corregir por software.

Método 4: Reparar con DISM

Si SFC no es suficiente, usa DISM para restaurar la imagen del sistema:

DISM /Online /Cleanup-Image /RestoreHealth

Este comando descarga los archivos que faltan de Internet y restaura la imagen de Windows. Duración: 15-45 minutos.
