Errores de Windows Update – Todos los códigos resueltos

Guía 📅 Actualizado: 2024 ⏱ Lectura: ~5 min 🖥️ Windows 10 & 11

Las actualizaciones de Windows son esenciales para la seguridad y estabilidad del sistema. Cuando el proceso de actualización falla con un código de error, necesitas saber cómo reaccionar. Esta guía cubre todos los problemas comunes de Windows Update.

Índice de contenidos

  1. Códigos de error de Windows Update más frecuentes
  2. Método 1: Solucionador de problemas de Windows Update
  3. Método 2: Vaciar la caché de Windows Update
  4. Método 3: DISM para reparar la imagen del sistema

Códigos de error de Windows Update más frecuentes

  • 0x80070422 – servicio Windows Update desactivado
  • 0x80240034 – problema al descargar las actualizaciones
  • 0x8007000E – memoria insuficiente durante la actualización
  • 0x80073712 – archivos de actualización corruptos
  • 0x800F081F – archivo de origen no encontrado
  • 0xC1900101 – error de controlador durante la actualización

Método 1: Solucionador de problemas de Windows Update

  1. Ve a Configuración → Sistema → Solucionar problemas
  2. Haz clic en Otros solucionadores de problemas
  3. Encuentra Windows Update y haz clic en Ejecutar
  4. Sigue las instrucciones y aplica las correcciones sugeridas

Método 2: Vaciar la caché de Windows Update

net stop wuauserv net stop cryptSvc net stop bits ren C:\Windows\SoftwareDistribution SoftwareDistribution.old net start wuauserv net start cryptSvc net start bits

Introduce estos comandos en el Símbolo del sistema (Administrador). Reinicia y vuelve a intentar instalar las actualizaciones.

Método 3: DISM para reparar la imagen del sistema

DISM /Online /Cleanup-Image /RestoreHealth

Ejecuta después sfc /scannow y vuelve a iniciar Windows Update.
