Windows no arranca – Guía completa de reparación

Guía 📅 Actualizado: 2024 ⏱ Lectura: ~5 min 🖥️ Windows 10 & 11

¿Windows 10 o 11 no arranca? Pantalla negra, bucle de arranque o mensaje de error al iniciar – son situaciones estresantes pero reparables. Esta guía presenta todos los métodos probados para volver a iniciar Windows.

Índice de contenidos

  1. Identificar el tipo de problema
  2. Método 1: Reparación automática de inicio
  3. Método 2: Reconstruir el BCD manualmente
  4. Método 3: Restaurar el sistema

Identificar el tipo de problema

Primero determina qué ves en la pantalla:

  • Pantalla negra con cursor – problema de visualización o archivos de arranque corruptos
  • «No se encontró sistema operativo» – error MBR/GPT o disco no detectado
  • Bucle de arranque – Windows intenta repararse en bucle sin éxito
  • Círculo de carga detenido – archivos del sistema o controladores corruptos
  • Pantalla azul al arrancar – ver la guía de BSOD

Método 1: Reparación automática de inicio

  1. Fuerza 3 reinicios (mantén pulsado el botón de encendido 5 segundos)
  2. Windows lanza automáticamente el Entorno de recuperación de Windows (WinRE)
  3. Elige Solucionar problemas → Opciones avanzadas → Reparación de inicio
  4. Espera a que finalice el proceso y reinicia
💡 Consejo: La reparación automática corrige la mayoría de errores BCD y problemas de arranque comunes en pocos minutos.

Método 2: Reconstruir el BCD manualmente

Si la reparación automática falla, reconstruye manualmente la configuración de arranque:

  1. Arranca desde un medio de instalación de Windows (USB/DVD)
  2. Elige Reparar el equipo → Solucionar problemas → Símbolo del sistema
  3. Introduce estos comandos uno a uno:
bootrec /fixmbr bootrec /fixboot bootrec /scanos bootrec /rebuildbcd

Escribe después exit y reinicia el ordenador.

Método 3: Restaurar el sistema

  1. Accede a WinRE (3 reinicios forzados)
  2. Elige Solucionar problemas → Opciones avanzadas → Restaurar sistema
  3. Selecciona un punto de restauración anterior al problema
  4. Sigue las instrucciones y espera a que finalice
