Problemas de WiFi en Windows 10/11 – Guía de reparación

Guía 📅 Actualizado: 2024 ⏱ Lectura: ~5 min 🖥️ Windows 10 & 11

Los problemas de conexión WiFi en Windows son muy frecuentes. Ya sea que la red no se detecte, la conexión se interrumpa constantemente o Internet no funcione a pesar de estar conectado – aquí encontrarás todas las soluciones.

Problemas de WiFi comunes en Windows

  • La tarjeta WiFi no detecta ninguna red
  • Conectado al WiFi pero sin acceso a Internet
  • La conexión WiFi se corta regularmente
  • Conexión WiFi muy lenta
  • Mensaje «Red no identificada»
  • El icono de WiFi ha desaparecido de la barra de tareas

Método 1: Restablecer la pila de red TCP/IP

netsh winsock reset netsh int ip reset ipconfig /release ipconfig /flushdns ipconfig /renew

Introduce cada comando en el Símbolo del sistema (Administrador) y pulsa Intro. Reinicia el PC después.

Método 2: Reinstalar el controlador WiFi

  1. Abre el Administrador de dispositivos (Win + X)
  2. Expande Adaptadores de red
  3. Clic derecho en el adaptador WiFi → Desinstalar dispositivo
  4. Marca la casilla para eliminar el controlador
  5. Reinicia – Windows reinstala el controlador automáticamente

Método 3: Restablecer la configuración de red

  1. Ve a Configuración → Red e Internet
  2. Desplázate hasta Restablecimiento de red
  3. Haz clic en Restablecer ahora
  4. Confirma y espera el reinicio
⚠️ Atención: El restablecimiento de red elimina todas las contraseñas WiFi guardadas y las configuraciones VPN.
